# Telegram-бот для репоста медиа без источника

Бот принимает картинки, видео и GIF (в том числе пересланные из других каналов, вместе с источником и подписями) и публикует их в твой канал **без пометки «Переслано из…» и без исходной подписи**. Собственная подпись (например, призыв поддержать канал бустом) добавляется автоматически к каждому N-му посту.

## Возможности

- Фото, видео и GIF, присланные или пересланные боту.
- Альбомы (несколько файлов сразу), включая смешанные: фото вместе с видео.
- Картинки и видео, отправленные «как файл».
- Ссылки на посты вида `https://t.me/канал/номер`.
- Сообщения со ссылкой-превью: бот берёт картинку или видео со страницы.
- Посты из расширенного текстового редактора Telegram (Rich Message): бот достаёт из них фото, видео и GIF и публикует без текста.
- Готовая подпись со ссылками, жирным, курсивом и другой разметкой.
- Автоматическая подпись только у каждого N-го поста (по умолчанию у каждого 10-го).
- Предпросмотр подписи после её сохранения и проверка её длины.
- Несколько администраторов, список задаётся в коде.

## Требования

- Python 3.10 или новее (проверено на 3.11).
- Библиотека `aiogram` 3.x (лучше свежая версия, нужна для постов из расширенного редактора).
- Библиотека `aiohttp` (ставится вместе с `aiogram`).
- Бот, созданный у [@BotFather](https://t.me/BotFather).
- Канал, в котором бот назначен администратором с правом публикации сообщений.

## Установка

```bash
git clone <адрес-репозитория>
cd <папка-проекта>
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -U aiogram
```

Для хостинга создай `requirements.txt`:

```
aiogram
```

Номер версии лучше не закреплять, чтобы подтягивалась свежая сборка.

## Настройка

В начале `bot.py` задай три обязательных значения:

```python
TOKEN = "123456789:AA...токен_от_BotFather"
CHANNEL_ID = -1001234567890
ADMINS = {111111111, 222222222, 333333333}
```

| Параметр | Что это |
| --- | --- |
| `TOKEN` | Токен бота от @BotFather, в кавычках. |
| `CHANNEL_ID` | Канал, куда бот публикует. Публичный канал: `"@имя_канала"` (в кавычках). Приватный: числовой ID с префиксом `-100` (число, без кавычек). |
| `ADMINS` | Telegram ID людей, которым разрешено пользоваться ботом. Свой ID можно узнать у [@userinfobot](https://t.me/userinfobot). |

**Как писать `ADMINS`.** Числа без кавычек, через запятую, внутри фигурных скобок `{ }`. Пробелы после запятых на работу не влияют. Чтобы добавить администратора, допиши его ID в список и перезапусти бота.

Если `ADMINS` оставить пустым (`ADMINS = set()`), ботом сможет пользоваться любой. Так делать не стоит.

**Про ID канала.** У приватных каналов ID всегда начинается с `-100`. Если в адресе канала видно число `2188730333`, в настройку нужно писать `-1002188730333`. Без префикса бот получит ошибку «chat not found».

**Безопасность токена.** Не выкладывай файл с токеном в публичный репозиторий. Если токен где-то засветился, перевыпусти его у @BotFather командой `/revoke`.

### Подпись по умолчанию и частота

Ниже в `bot.py` есть две необязательные настройки:

```python
DEFAULT_CAPTION = (
    '<a href="https://t.me/boost/kavaikiti">поддержи канал бустом</a> '
    "https://t.me/boost/kavaikiti"
)
DEFAULT_EVERY = 10
```

- `DEFAULT_CAPTION` работает, пока командой `/caption` не задана другая. Если файл `settings.json` пропал (например, при перезапуске хостинга), бот вернётся к этой подписи.
- `DEFAULT_EVERY` задаёт, к какому по счёту посту добавляется подпись. `10` означает, что подпись получают 10-й, 20-й, 30-й посты и так далее. `1` означает подпись у каждого поста.

## Запуск

```bash
python bot.py
```

Перед первым запуском проверь файл на ошибки отступов:

```bash
python -m py_compile bot.py
```

В файле должны быть только пробелы, без табов. Файл лучше вставлять целиком, а не кусками.

### Запуск как служба на Linux (systemd)

Файл `/etc/systemd/system/repostbot.service`:

```ini
[Unit]
Description=Telegram repost bot
After=network-online.target

[Service]
WorkingDirectory=/opt/repostbot
ExecStart=/opt/repostbot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now repostbot
journalctl -u repostbot -f      # логи
```

### Хостинг

Бот работает через long polling, входящие порты открывать не нужно. Подойдёт любой небольшой VPS. На платформах с «Web Service» выбирай тип **Worker / Background Worker**, иначе платформа не увидит открытый порт и будет перезапускать бот (в логах появится `Received SIGTERM`). Бесплатные тарифы, которые усыпляют сервис при простое, для polling-бота не подходят.

Файл `settings.json` (подпись, частота, счётчик) хранится рядом с `bot.py`. На хостингах без постоянного диска он может пропадать при перезапуске: счётчик начнётся заново, а подпись и частота вернутся к значениям из кода.

## Команды

Команды доступны только администраторам из `ADMINS`. Настройки общие для всех администраторов.

| Команда | Действие |
| --- | --- |
| `/start` | Справка. |
| `/caption текст` | Задать подпись. После сохранения бот присылает предпросмотр. |
| `/every N` | Добавлять подпись к каждому N-му посту. `/every 1` означает подпись у каждого поста. Счётчик при этом обнуляется. |
| `/nocaption` | Отключить подпись. Вернуть можно командой `/caption`. |
| `/status` | Показать канал, частоту, счётчик постов, сколько осталось до поста с подписью, и текущую подпись. |
| `/test` | Проверить, что бот видит канал и является в нём администратором. |

## Подпись со ссылкой

Ссылку в подписи можно задать тремя способами:

1. **Markdown-запись:**
   ```
   /caption [поддержи канал бустом](https://t.me/boost/kavaikiti)
   ```
2. **HTML-запись:**
   ```
   /caption <a href="https://t.me/boost/kavaikiti">поддержи канал бустом</a>
   ```
3. **Меню форматирования Telegram:** набери `/caption поддержи канал бустом`, выдели слова, нажми «Ссылка» и вставь адрес.

Что нужно знать:

- После команды бот присылает готовый вид подписи. Если слова нажимаются как ссылка, в канале будет так же.
- Если разметка некорректна, бот сообщит об ошибке и не сохранит подпись.
- Символы `<`, `>` и `&` в обычном тексте экранируются автоматически.
- Подпись к медиа не может быть длиннее 1024 символов. При превышении бот предупредит.
- Если после слов со ссылкой написать ещё и голый адрес, он будет виден в подписи целиком.

## Как считаются посты

- Один пост равен одной публикации в канал. Альбом, пост из расширенного редактора и ссылка на пост считаются как один пост, сколько бы файлов в них ни было.
- Счётчик общий для всех администраторов и растёт с каждой публикацией.
- Подпись добавляется, когда номер поста делится на N без остатка. При N = 10 это посты 10, 20, 30 и так далее. Остальные посты публикуются без подписи.
- Счётчик увеличивается в момент попытки публикации, даже если Telegram отклонил пост из-за ошибки.

## Как пользоваться

1. Отправь боту `/test` и убедись, что статус бота в канале `administrator`.
2. При желании задай подпись (`/caption`) и частоту (`/every`).
3. Перешли или пришли боту:
   - картинку, видео, GIF или альбом;
   - пост из расширенного редактора;
   - ссылку на пост `t.me/канал/номер`;
   - сообщение со ссылкой на страницу с картинкой.
4. Бот опубликует файлы в канал и ответит «✅ Опубликовано». При ошибке он напишет причину.
5. Командой `/status` можно посмотреть, через сколько постов будет подпись.

## Как это работает

- Для файлов, присланных боту, используется `file_id`: бот отправляет файл в канал заново, поэтому пометка об источнике и исходная подпись не попадают в публикацию.
- Для ссылок на публичные посты бот скачивает файлы со страницы поста и загружает их в канал. Если не получилось, он пробует `copy_message`.
- Для постов из расширенного редактора бот обходит блоки сообщения (поле `rich_message`), собирает все фото, видео и GIF и публикует их без остального текста.
- Фото и видео одного поста уходят одним альбомом (до 10 штук), GIF отправляются отдельно.
- Подпись хранится в HTML и отправляется в режиме `HTML`.

## Ограничения

- Бот может загружать файлы размером до 50 МБ. Для файлов, присланных напрямую, лимит не действует, так как они отправляются по `file_id`.
- Ссылки на приватные каналы (`t.me/c/...`) работают, только если бот состоит в этом канале. Иначе перешли пост самому боту.
- Если в канале-источнике включена защита контента, пересылка запрещена. Сохрани файл вручную и отправь боту.
- GIF по ссылке определяются по признаку зацикленного видео. Иногда они приходят как обычное видео.
- Структура блоков видео и GIF в постах из расширенного редактора проверена не полностью. Если бот отвечает «Не нашёл картинок. Типы блоков: …», для такого блока нужна доработка.

## Частые проблемы

| Симптом | Причина и решение |
| --- | --- |
| Ошибка `chat not found` или `bot is not a member` | Неверный `CHANNEL_ID` (нет `-100`) или бот не администратор канала. |
| Бот молчит на `/start` | Бот не запущен либо твоего ID нет в `ADMINS`. |
| `Token is invalid ... NoneType` | Токен не задан. Проверь строку `TOKEN`. |
| `IndentationError` | В файле смешаны табы и пробелы или код вставлен кусками. Вставляй файл целиком. |
| `TypeError: getenv() takes from 1 to 2 positional arguments` | В `os.getenv(...)` подставлены значения вместо имени переменной. Задавай значения прямо в `TOKEN`, `CHANNEL_ID`, `ADMINS`. |
| Бот отвечает «⛔ Нет доступа. Твой ID: …» | Добавь указанный номер в `ADMINS`. |
| «Не знаю, как опубликовать это сообщение (тип: …)» | Тип сообщения не поддерживается. Укажи его при обращении за доработкой. |
| Подпись не появляется у постов | Так и задумано: подпись только у каждого N-го поста. Проверь `/status` и при необходимости задай `/every 1`. |
| Ссылка в подписи пропадает | Задай подпись заново командой `/caption` одним из трёх способов выше и проверь предпросмотр. |
| Подпись или счётчик сбросились | Файл `settings.json` потерян при перезапуске хостинга, либо другой администратор отправил `/caption`, `/every` или `/nocaption`. Проверь `/status`. |
| В логах `Received SIGTERM` | Хостинг остановил контейнер: редеплой, неверный тип сервиса или закончился лимит тарифа. |
| Посты из расширенного редактора не публикуются | Обнови `aiogram` до последней версии и перезапусти бота. |
